# Guard FF Patch

NeoForge 1.21.1 server-side patch for [Guard Villagers](https://www.curseforge.com/minecraft/mc-mods/guard-villagers): guard projectiles no longer damage players unless the guard is actually targeting that player. Clients don't need it.

Downloads: [GitHub Releases](https://github.com/hammerknife404/gvs-noatk-players/releases). **Documentation:** [the wiki](https://github.com/hammerknife404/gvs-noatk-players/wiki) covers what it changes, installation, and building and releasing.
